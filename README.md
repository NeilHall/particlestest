React + [Vite](https://vite.dev/).

## Scripts

- `npm start` (or `npm run dev`) — dev server on http://localhost:5173
- `npm run build` — production build to `dist/`
- `npm run preview` — serve the built `dist/` locally
- `npm test` — [Vitest](https://vitest.dev/) in watch mode (`npx vitest run` for one pass)
